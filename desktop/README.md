# BLACKSITE: Extraction — Desktop

Native Godot 4.7.2 desktop vertical slice. The Windows build is exported as a standalone executable with the game data embedded.

## Controls
- WASD — Move
- Mouse — Look
- Left mouse — Fire
- Right mouse — Aim down sights
- Shift — Sprint
- Ctrl — Crouch
- R — Reload
- F — Interact / loot / extract
- 1 / 2 / 3 — M4A1 / pistol / pump shotgun
- Tab — Field inventory
- Esc — Release mouse cursor

## Contract
Recover the Black Tide archive drive near the southern warehouse/pier complex and return to Gate 3. Optional valuables are lost on death and permanently added to the stash only after extraction.

## Art sources
The CI build pulls a curated subset of CC0/public-domain assets from `petroulacl/fps-asset-kit`: PBR ambientCG surfaces, GLB weapons, and firearm SFX. All map layout, UI, code, encounter logic, item economy and environmental storytelling are original to BLACKSITE: Extraction.
